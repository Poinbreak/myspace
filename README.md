# MySpace

A personal, minimal, Notion-like grayscale workspace with dark theme layout.

## Features
- **Dashboard:** Clock, dynamic greetings, task completion metrics, and logs overview.
- **To-Do Board:** Notion-style Kanban board to track and update task progress.
- **Sandbox Canvas:** Interactive canvas area to drag, resize, and connect sticky notes using directed arrow paths.
- **Project Log:** Chronological update log to document project thoughts and trending tags.
